# FPGA Retinex Low-Light Image Enhancement

This repository brings together the current streaming Verilog implementation, its image-stream testbench, and the conference comparison of the base-paper PWL Retinex method with five existing enhancement methods.

> **Scope of the results:** the paper's PWL image-quality values were generated by the software implementation. They are not bit-accurate outputs from this RTL. The paper's ExDark accuracy and macro precision measure one frozen detector's category response, not reference-image enhancement accuracy. No common FPGA cost table for all six methods is included.

## Project walkthrough

### Step 1 — Estimate illumination from the RGB stream

`rtl/retinex_top_level.v` is the top module. `rgb_to_gi.v` generates the maximum RGB channel used as guidance. `line_buffer_10x.v`, `col_max_11.v`, and `window_max_generator.v` form the 11 × 11 local maximum used as coarse illumination.

### Step 2 — Refine illumination while preserving edges

`col_min_11.v`, `filter_node.v`, `linear_approx_gamma.v`, and `edge_preserving_filter.v` form the edge-aware refinement stage. The exponential weighting is approximated with piecewise-linear arithmetic. ROM data used by the design is stored beside the RTL as `.mem` files.

### Step 3 — Recover reflectance and remap illumination

`reflectance_calc.v` estimates reflectance using an inverse-illumination lookup table. `illumination_modifier.v` remaps illumination, and the top module recombines the channels into the enhanced RGB stream.

### Step 4 — Stream and capture an image in simulation

`sim/tb_system.v` drives warm-up, image, and flush phases, then writes enhanced RGB pixels to PPM and HEX outputs. The current source and testbench use `IMG_W = 100`. Change the width consistently in both files for a different image width. The testbench expects `input_image.hex` in the simulator's working directory; that dataset-derived image vector is not included.

The delay constants in the current source describe 28 cycles of guidance alignment, 38 cycles to the refined illumination path, and a 40-cycle end-to-end pixel/output schedule in the testbench. These are implementation comments and testbench assumptions; run the simulation in the target Vivado setup to confirm behavior for a chosen input.

### Step 5 — Compare enhancement methods

The paper compares PWL Retinex with Retinex-DIP, LiCENt, EnlightenGAN, KinD, and LIME using:

- Paired-reference scores on LOL-v1 and LOL-v2 Real: PSNR, SSIM, RGB MAE, VIF, and CIEDE2000.
- No-reference quality predictors on DICM, the LIME image collection, NPE, and VV: NIQE, BRISQUE, NIQMC, and BLIINDS-II.
- A separate ExDark detector-response experiment with image-label accuracy, macro precision, and per-method confusion matrices.

Tables, figures, paper files, and the retained per-image data are organized in `paper/` and `results/`. Dataset images and model checkpoints are excluded. See [dataset and metric definitions](docs/DATASETS_AND_METRICS.md) and [reproducibility limitations](docs/REPRODUCIBILITY.md).

### Step 6 — Recreate the ExDark summary plot

Install the small analysis dependencies and run from the repository root:

```bash
python -m pip install -r requirements-analysis.txt
python scripts/analyze_exdark_predictions.py
```

This reconstructs the ExDark summary, six confusion-matrix CSVs, and their combined figure from the committed predictions. It does not rerun enhancement networks or detector inference.

## Vivado setup

The source project metadata selected part `xc7z020clg400-1`. No board constraints or machine-specific `.xpr` project file are included.

1. Create a Vivado project and select the part `xc7z020clg400-1`.
2. Add the Verilog files under `rtl/` as design sources and set `retinex_top_level` as the synthesis top.
3. Add the three `.mem` files under `rtl/` as memory initialization files; preserve the names referenced by `$readmemh`.
4. Add `sim/tb_system.v` as a simulation source and set `tb_system` as the simulation top.
5. Supply a 100 × 100 RGB `input_image.hex` in the simulator run directory. Use the pixel packing expected by the testbench: red in bits `[23:16]`, green in `[15:8]`, and blue in `[7:0]`.
6. Run behavioral simulation and inspect `enhanced_image.ppm` or `output_image.hex` in the simulation directory.

## Paper files

Start with [`paper/pwl_retinex_comparison.tex`](paper/pwl_retinex_comparison.tex). Keep the sibling `paper/latex_figures/` directory when compiling. The matching PDF and editable DOCX are included as exports. The repository's currently retained source/results do not include a complete automated rerun for all learned methods; their checkpoints and full source repositories must be obtained separately.
