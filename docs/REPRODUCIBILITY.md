# Reproducibility notes

See [the step-by-step project walkthrough](PROJECT_WALKTHROUGH.md) for the RTL flow and study sequence.

## What is included

- The current conference-paper draft in LaTeX, PDF, and editable Word format.
- The LaTeX figure assets under `paper/latex_figures/`.
- Reported paired and no-reference tables, retained LOL-v1 per-image metrics and ranges, and the figures used by the paper.
- ExDark predictions for the common balanced sample, per-method confusion matrices, the summary table, and the combined plot.
- A dependency-light script that reconstructs the ExDark summary and confusion matrices from the saved predictions.
- The existing Verilog modules and testbench at repository root.

## What is intentionally not included

The image datasets, object annotations, downloaded model checkpoints, and third-party implementation repositories are not committed. They are large and may have separate distribution terms. Obtain each dataset and checkpoint from its official source and preserve its license/terms. The `.gitignore` excludes common local dataset, checkpoint, environment, and generated-output folders.

## Experimental caveats to preserve

1. The paired PWL scores were generated by the software PWL method, not bit-accurate Verilog/RTL simulation.
2. The ExDark result uses the same balanced 240-image sample for all six methods and a single fixed detector. It should be described as detector response on this sample, not a general enhancement accuracy score.
3. Retinex-DIP used 20 per-image optimization steps for the CPU ExDark detector run. This reduced budget differs from its longer paired-image evaluation.
4. The blind no-reference metric averages have unequal output coverage; they are descriptive and not a fully matched per-image statistical comparison.
5. Paired scores are reported as means and observed per-image ranges; the range bars are not standard deviations or run-to-run uncertainty estimates.
6. The retained paired protocol uses five-pass averages for methods with repeated outputs; LiCENt is represented by one deterministic pass. This distinction is documented in the paper.
7. No common hardware, energy, memory, or latency measurement was retained for all methods. Do not infer a numerical FPGA quality-versus-cost ranking from image-quality results.

## Regenerating the ExDark figure

From the repository root:

```bash
python -m pip install -r requirements-analysis.txt
python scripts/analyze_exdark_predictions.py
```

The source prediction file is `results/exdark/exdark_predictions_six_methods_balanced240.csv`. The script only recomputes descriptive metrics and visualization; it does not rerun image enhancement or detector inference. Full neural-model reproduction additionally requires the original source/checkpoint versions, packages, and input datasets used for that model.
